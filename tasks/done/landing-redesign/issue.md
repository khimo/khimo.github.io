## Summary
Rebuild the khimo.github.io homepage on the khimo "The Signal" design system,
keeping all original content but presenting it in the new visual language.

## Context / why
The old landing page did not reflect the khimo brand. The redesign establishes
"The Signal" language on the most visible page and sets the tone for the rest of
the site renewal.

## Acceptance criteria
- [x] Full-viewport hero with an animated Signal Path SVG.
- [x] Stark "92 integrations" headline stat.
- [x] All original landing content restored (nothing dropped).
- [x] New VISUAL Essential vs PRO comparison.
- [x] "Works with" logo wall.
- [x] Bang & Olufsen positioning section.

## Notes / progress
- The 21 individual features were regrouped into **5 capability cards**.
- Comparison convention: coral checkmark = available in both tiers; coral
  "PRO" pill = PRO-only.
- B&O framed as "Every Bang & Olufsen product": TVs, audio, remotes; scenes
  triggered from a B&O remote; home status shown on the TV.
- Done and verified.
